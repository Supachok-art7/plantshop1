# ร้านสวนสุข — ระบบร้านค้าต้นไม้/ดอกไม้ (PHP + MySQL สำหรับ XAMPP)

## ติดตั้ง
1. เปิด XAMPP แล้ว Start **Apache** และ **MySQL**
2. วางโฟลเดอร์ `plantshop` ไว้ที่ `C:\xampp\htdocs\plantshop`
3. สร้างฐานข้อมูล เลือกวิธีใดวิธีหนึ่ง
   - phpMyAdmin → แท็บ Import → เลือก `database/database.sql` (แนะนำ)
   - หรือเปิด http://localhost/plantshop/tools/install.php แล้วลบไฟล์นี้ทิ้ง
4. เข้าร้านที่ http://localhost/plantshop/
ถ้า MySQL ตั้งรหัสผ่านไว้ แก้ที่ `includes/config.php` (DB_USER / DB_PASS)

**อัปเดตจากรุ่นเก่าโดยไม่ลบข้อมูล:** นำเข้าไฟล์ตามลำดับ ครั้งละ 1 ไฟล์ (จากรุ่นแรก `update_v2.sql` → `update_v3.sql` → `update_v4.sql` → `update_v5.sql`)
ถ้าใช้อยู่ที่ v3 ให้นำเข้า **`update_v4.sql`** อย่างเดียว (เพิ่มตาราง `reports` สำหรับระบบแจ้งรายงาน และข้อมูลติดต่อร้าน)
> ถ้ายังไม่ได้นำเข้า `update_v4.sql` เว็บยังใช้งานได้ปกติ เพียงแต่หน้า "แจ้งรายงาน" จะแจ้งว่าระบบยังไม่พร้อม

**ฐานข้อมูลพัง / เผลอแก้แล้วใช้งานไม่ได้ (วิธี SQL):** phpMyAdmin → แท็บ SQL → วางไฟล์ `fix_database.sql` → Go (รันซ้ำได้ ไม่ลบข้อมูลเดิม ใช้ได้กับ MariaDB ของ XAMPP) หรือจะใช้ตัวซ่อมผ่านเว็บแทนก็ได้:

**ตัวซ่อมผ่านเว็บ:** เปิด `http://localhost/plantshop/tools/repair_db.php` ครั้งเดียว ระบบจะตรวจและซ่อมให้ (สร้างตาราง/คอลัมน์ที่หาย, เปิด AUTO_INCREMENT/PRIMARY KEY ที่หลุด, เติมหมวดหมู่และตั้งค่าร้านที่หาย, คืนแอดมิน) โดยไม่ลบข้อมูลเดิม เพิ่ม `?reset_pw=1` เพื่อรีเซ็ตรหัสผ่านบัญชีทดลอง ใช้เสร็จให้ลบไฟล์ทิ้ง

## สิ่งที่เพิ่มในรุ่น v4
- **โปรไฟล์ใหม่:** ภาพปก + รูปโปรไฟล์ (กดไอคอนกล้องเพื่ออัปโหลดทันที) สถิติ (ออเดอร์ ยอดซื้อ รีวิว เรื่องที่แจ้ง) แถบความสมบูรณ์ของโปรไฟล์ เมนูด้านข้าง ปักหมุดบ้านด้วยตำแหน่งปัจจุบันได้ ประวัติสั่งซื้อแบบการ์ดพร้อมแถบความคืบหน้า
- **แถบเมนูครบ:** โลโก้ ค้นหา แชท ตะกร้า เมนูสมาชิก (ดรอปดาวน์) เมนูหลักพร้อมดรอปดาวน์หมวดสินค้า รองรับมือถือ (ปุ่ม ☰) ตัวเลขแจ้งเตือน และส่วนท้ายเว็บ (footer) พร้อมลิงก์ช่วยเหลือ/นโยบาย/ช่องทางติดต่อ
- **หน้าใหม่:** เกี่ยวกับเรา, ติดต่อเรา (พร้อมแผนที่ร้าน), คำถามที่พบบ่อย, นโยบาย (การจัดส่ง การคืนสินค้า ความเป็นส่วนตัว เงื่อนไข) และหน้า error 403/404 ที่สวยงาม
- **แจ้งรายงานถึงแอดมิน:** สมาชิกแจ้งปัญหา (ออเดอร์ สินค้า ชำระเงิน รีวิวไม่เหมาะสม ฯลฯ) พร้อมแนบรูปได้ที่ `report.php` หรือกดปุ่ม 🚩 จากหน้าออเดอร์/สินค้า/รีวิว แอดมินเห็นตัวเลขแจ้งเตือน ตอบกลับ และเปลี่ยนสถานะที่หลังบ้านแท็บ "รายงาน" สมาชิกเห็นคำตอบที่ "รายงานของฉัน" (จำกัดวันละ 5 เรื่องกันสแปม)
- **หลังบ้าน:** แท็บ "รายงาน" และ "ข้อมูลร้าน" (เบอร์ อีเมล LINE ที่อยู่ เวลาทำการ ที่แสดงในหน้าติดต่อและท้ายเว็บ)
- หลังล็อกอินระบบพากลับไปหน้าที่ตั้งใจจะเข้า (เช่น เข้า "แจ้งรายงาน" ตอนยังไม่ล็อกอิน)

หมายเหตุ: ข้อความในหน้านโยบาย/FAQ และข้อมูลติดต่อร้านเป็นแม่แบบ ควรปรับให้ตรงกับร้านจริง (นโยบายแก้ที่ `policy.php`, FAQ แก้ที่ `faq.php`, ข้อมูลติดต่อแก้ในหลังบ้าน)

## เพิ่มล่าสุด: Google Analytics 4 (ตาม PDPA) และหน้า 404
- **GA4 โหลดเฉพาะเมื่อผู้เยี่ยมชมกด "ยอมรับทั้งหมด"** ในแบนเนอร์คุกกี้: หลังบ้าน → แท็บ "ข้อมูลร้าน" → ช่อง "สถิติการเข้าชม" ใส่รหัสวัดผล `G-XXXXXXXXXX` (เว้นว่าง = ไม่ใช้ GA เลย)
  - ไม่ทำงานเมื่อเลือก "เฉพาะที่จำเป็น", ไม่ติดตามแอดมิน, ทำงานเฉพาะหน้าสาธารณะ (หน้าแรก สินค้า ตะกร้า เกี่ยวกับเรา ติดต่อ FAQ นโยบาย) ไม่ทำงานในหน้าบัญชี ชำระเงิน แชท ติดตามพัสดุ แจ้งรายงาน ศูนย์ PDPA
  - ปิดสัญญาณโฆษณา (Google Signals / ad personalization) และตั้ง Consent Mode เป็น ad_*=denied
  - ถ้าผู้ใช้เปลี่ยนใจเป็น "เฉพาะที่จำเป็น" ระบบลบคุกกี้ `_ga*` ให้ และบันทึกการถอนความยินยอมในประวัติ (สมาชิก)
  - ข้อความในแบนเนอร์ ศูนย์ความเป็นส่วนตัว และนโยบายคุกกี้เปลี่ยนตามอัตโนมัติเมื่อมีรหัส GA4 — ควรเพิ่ม Google LLC ในรายชื่อผู้ประมวลผล/โอนข้อมูลข้ามประเทศตามนโยบายของร้านด้วย
  - ยังไม่ได้ใส่ Facebook Pixel (ถ้าจะเพิ่มใช้เงื่อนไขเดียวกันได้ที่ `analytics_snippet()` ใน `pdpa_lib.php`)
- **หน้า 404** (`404.php`) พร้อมช่องค้นหา หมวดหมู่ และสินค้ามาใหม่ ตอบรหัส 404 จริง ไม่ให้เสิร์ชเอนจินจัดทำดัชนี
- **`.htaccess`** (ต้องคัดลอกไปพร้อมโฟลเดอร์ ไฟล์ขึ้นต้นด้วยจุดอาจถูกซ่อนในบางโปรแกรม): ที่อยู่ที่ไม่มีอยู่จริงแสดง 404.php (ใช้ mod_rewrite ไม่ผูกกับชื่อโฟลเดอร์) ปิดการแสดงรายชื่อไฟล์ ห้ามเปิดไฟล์ .sql/.md/.log จากเว็บ และเพิ่มส่วนหัวความปลอดภัยพื้นฐาน

## แผนผังไฟล์ (แต่ละไฟล์มีคอมเมนต์อธิบายด้านบนและก่อนฟังก์ชันทุกตัว)
| ไฟล์ | หน้าที่ |
|---|---|
| `includes/config.php` | ไฟล์กลาง: ตั้งค่า DB, session, ฟังก์ชันช่วย (q, e, csrf, me, need, ppay, save_img, head, foot, card, fail, badge_counts, shop_info) |
| `index.php` | หน้าแรก (landing): สไลด์โฆษณา จุดเด่นร้าน ช้อปตามหมวด สินค้ามาใหม่ ขายดี |
| `tools/repair_db.php` | ตัวซ่อมฐานข้อมูล (ใช้เสร็จลบทิ้ง) |
| `products.php` | หน้าสินค้า: แถบหมวดหมู่ซ้ายมือ + รายการสินค้า ค้นหา/เรียงลำดับ |
| `product.php` | หน้าสินค้า: รายละเอียด รีวิว (แนบรูป) สินค้าที่เกี่ยวข้อง |
| `cart.php` | ตะกร้า + สั่งซื้อ + ปักหมุดจัดส่ง |
| `pay.php` | ชำระเงิน: QR PromptPay เลขบัญชี แนบสลิป |
| `login.php` / `register.php` / `logout.php` | เข้าสู่ระบบ / สมัครสมาชิก / ออกจากระบบ |
| `account.php` | โปรไฟล์ของฉัน: หัวโปรไฟล์+สถิติ ข้อมูลส่วนตัว/ที่อยู่ ปักหมุดบ้าน ยืนยันตัวตน เปลี่ยนรหัสผ่าน ประวัติสั่งซื้อ |
| `report.php` | แจ้งรายงานถึงแอดมิน + รายงานของฉัน (ดูคำตอบ/สถานะ) |
| `about.php` / `contact.php` / `faq.php` / `policy.php` | เกี่ยวกับเรา / ติดต่อเรา / คำถามที่พบบ่อย / นโยบายและเงื่อนไข |
| `assets/js/app.js` | สคริปต์เมนูมือถือ เมนูสมาชิก ข้อความแจ้งเตือน |
| `track.php` | ติดตามออเดอร์: ไทม์ไลน์ ขนส่ง/เลขพัสดุ แผนที่ ประวัติ ยืนยันรับสินค้า |
| `file.php` | เปิดดูเอกสารยืนยันตัวตนใน `private/` (แอดมินเท่านั้น) |
| `chat.php` | แชทลูกค้า–ร้าน |
| `admin.php` | หลังบ้านแอดมิน (ภาพรวม ออเดอร์ สินค้า สมาชิก แชท รายงาน แผนที่ หมวดหมู่ ยืนยันตัวตน โปรโมท ชำระเงิน ข้อมูลร้าน) |
| `assets/css/style.css` | หน้าตา/สีทั้งหมด (แก้สีที่ตัวแปรบนสุด) |
| `database/database.sql` / `fix_database.sql` / `update_v2.sql` / `update_v3.sql` / `update_v4.sql` / `update_v5.sql` / `tools/install.php` | สร้าง / อัปเดต / ติดตั้งอัตโนมัติ ฐานข้อมูล |
| `uploads/` | รูปสลิป รูปรีวิว รูปโปรไฟล์ (ห้ามรันไฟล์ PHP ในนี้) |
| `private/` | เอกสารยืนยันตัวตน (ปิดไม่ให้เปิดตรงจากเว็บ ลบทิ้งหลังตรวจเสร็จ) |

หมายเหตุ: QR แผนที่ และฟอนต์โหลดจากอินเทอร์เน็ต ต้องต่อเน็ตตอนใช้งาน


## จัดการสินค้า (แอดมิน)
หลังบ้าน → แท็บ **สินค้า**: เพิ่ม / แก้ไข / ลบสินค้า เปลี่ยนชื่อ หมวด ราคา สต็อก อีโมจิ คำอธิบาย และอัปโหลดรูปสินค้า (JPG/PNG/WEBP ไม่เกิน 3MB) ได้ รูปเก็บที่ `uploads/` ถ้าไม่มีรูปจะแสดงอีโมจิแทน ต้องรัน `update_v5.sql` (หรือ `fix_database.sql`) ก่อน เพื่อเพิ่มคอลัมน์ `products.image`

## สรุปยอดขาย (แอดมิน)
หลังบ้าน → แท็บ **📈 ยอดขาย**: เลือกช่วง 7/30/90 วัน, ปีนี้, ทั้งหมด (เทียบ % กับช่วงก่อนหน้า) ดูยอดขายรวม จำนวนออเดอร์/ชิ้น ยอดเฉลี่ยต่อออเดอร์ อัตราชำระสำเร็จ/ยกเลิก กราฟยอดขาย สถานะออเดอร์ ช่องทางชำระเงิน สัดส่วนยอดตามหมวดหมู่ (หมวดหลัก+หมวดย่อย) สินค้าขายดี Top 10 สินค้าขายไม่ดี/ไม่มียอด และสินค้ายอดนิยมจากรีวิว (นับเฉพาะออเดอร์ที่ชำระแล้ว) ไม่ต้องแก้ฐานข้อมูลเพิ่ม


## 🔏 ระบบ PDPA (v6)
- **อัปเดตฐานข้อมูล:** นำเข้า `database/update_v6.sql` 1 ครั้ง (หรือรัน `tools/repair_db.php`) · ติดตั้งใหม่ใช้ `database.sql` ได้เลย
- **สมาชิก:** แบนเนอร์คุกกี้ · ติ๊กยอมรับนโยบายตอนสมัคร (บันทึกเวอร์ชัน+เวลา) · ศูนย์ความเป็นส่วนตัว `privacy.php` (ดู/ถอนความยินยอม, ดาวน์โหลดข้อมูล JSON, ยื่นคำขอใช้สิทธิ์, ลบบัญชี)
- **แอดมิน:** แท็บ 🔏 PDPA (คำขอใช้สิทธิ์ครบกำหนด 30 วัน, ทะเบียนเหตุละเมิดข้อมูล 72 ชม., ตั้งเวอร์ชันนโยบาย/ระยะเวลาเก็บ, ล้างข้อมูลหมดอายุ, ROPA, บันทึกการเข้าถึง)
- **ไฟล์ใหม่:** `pdpa_lib.php` `pdpa_admin.php` `privacy.php` `consent.php` `export.php` · หน้านโยบายใหม่ `policy.php?p=privacy` และ `?p=cookies`
- ข้อความนโยบายเป็นแม่แบบ ควรให้ผู้เชี่ยวชาญด้านกฎหมายตรวจก่อนใช้งานจริง

## หน้าตรวจเช็คสำหรับครู/ผู้ตรวจ (demo_check.php)
- เปิดได้เฉพาะเมื่อเปิด "โหมดทดลอง" ในแอดมิน > ตั้งค่าร้าน (ปิดโหมดแล้วหน้านี้จะตอบ 404) และมีลิงก์ที่ท้ายเว็บ
- ใช้ตรวจข้อ 8 (GA4 โหลดเมื่อกด "ยอมรับทั้งหมด" เท่านั้น) และข้อ 9 (หน้า 404)
- เปิด `demo_check.php?sim=1` เพื่อจำลองรหัส GA4 ปลอม (G-DEMO000000) ให้เห็นตารางผลโดยไม่ติดต่อ Google
- ตารางในหน้านี้ใช้ฟังก์ชันเดียวกับที่เว็บใช้จริง (analytics_decision) จึงตรงกับพฤติกรรมจริง

**ทางลัดแบบง่าย:** ไม่ต้องล็อกอินหรือเปิดโหมดทดลอง แค่เปิด `http://localhost/plantshop/demo_check.php?sim=1` (ใช้ได้เมื่อร้านยังไม่ได้ตั้งรหัส GA4 จริง)

## เพิ่มล่าสุด (v7): ภาษี VAT · ค่าส่งตามระยะทาง · โค้ดส่วนลด · ต้นไม้สะสมแต้ม
- **ฐานข้อมูลเดิม:** import `database/update_v7.sql` (หรือเปิด `tools/repair_db.php` จาก localhost) · ติดตั้งใหม่: `database.sql` มีครบแล้ว
- **แอดมิน > 🧾 ภาษี/ค่าส่ง/โค้ด:** ตั้งอัตรา VAT (รวมในราคาแล้ว หรือบวกเพิ่ม), เลขผู้เสียภาษี, ค่าส่ง = ค่าเริ่มต้น + (กม. − ระยะแรก) × กม.ละกี่บาท ปัดขึ้นหลัก 5 บาท, ส่งฟรีเมื่อซื้อครบ, ส่งไกลสุดกี่ กม. และสร้าง/เปิด-ปิด/ลบโค้ดส่วนลด (ตัวอย่าง: WELCOME10, SAVE50, BIGTREE)
- **ระยะทาง** คือเส้นตรงจากพิกัดร้าน (แท็บ "ชำระเงิน") ถึงหมุดลูกค้า ไม่ใช่ระยะถนน · ไม่ปักหมุด = ใช้ค่าส่งมาตรฐาน
- **ตะกร้า:** ใส่โค้ด + เห็นสรุปยอดสด (สินค้า − ส่วนลด + ค่าส่ง + VAT) · ยอดจริงเซิร์ฟเวอร์คิดซ้ำตอนกดสั่งซื้อ ไม่เชื่อตัวเลขจากเบราว์เซอร์
- **ต้นไม้สะสมแต้ม** (โปรไฟล์ > 🌳): 500 บาท = 1 แต้ม สูงสุด 15 แต้ม · 6 ระดับ เมล็ด → ต้นกล้า → ต้นอ่อน → ต้นกลาง → ต้นใหญ่ → ต้นไม้ใหญ่ · แสดงเป็นโมเดล 3 มิติหมุนได้ (CSS ล้วน) · แต้มคำนวณจากออเดอร์ที่ชำระแล้ว โค้ดส่วนลดตั้งให้ใช้ได้เฉพาะระดับที่กำหนดได้
- **หน้า 404:** แก้ให้หาที่อยู่ฐานเว็บจากตำแหน่งไฟล์จริง CSS จึงโหลดได้เสมอแม้เปิดที่อยู่ซ้อนหลายชั้น

## ภาษาไทย / English (ปุ่ม 🌐 ไทย | EN ที่มุมขวาบนของทุกหน้า)
- กดปุ่มเพื่อสลับภาษา ระบบจำตัวเลือกด้วยคุกกี้ `lang` (1 ปี ตั้งเมื่อผู้ใช้กดเองเท่านั้น และระบุไว้ในนโยบายคุกกี้แล้ว)
- ใช้วิธี "แปลตอนแสดงผล": โค้ดและฐานข้อมูลยังเป็นภาษาไทยเหมือนเดิม คำแปลอยู่ใน `includes/i18n_en.php` (ไทย → อังกฤษ) เพิ่ม/แก้คำแปลได้โดยเพิ่มบรรทัด `'ข้อความไทย' => 'English',` (ข้อความยาวจะถูกจับคู่ก่อนข้อความสั้นเอง)
- แปลทั้งหน้าลูกค้า: หน้าแรก สินค้า ตะกร้า ชำระเงิน ติดตามพัสดุ โปรไฟล์ ต้นไม้สะสมแต้ม แจ้งรายงาน แชท FAQ นโยบาย PDPA และแบนเนอร์คุกกี้ รวมสินค้า/หมวดหมู่ตัวอย่างที่มากับ `database.sql`
- **ไม่แปล:** หลังบ้านแอดมิน (`admin.php`) หน้าตรวจเช็ค และไฟล์ดาวน์โหลด · สินค้า/หมวดที่แอดมินเพิ่มเองและข้อความที่ผู้ใช้พิมพ์ (รีวิว แชท รายงาน) จะแสดงตามภาษาที่พิมพ์ จนกว่าจะเพิ่มคำแปลใน `i18n_en.php`
